# Grade 2 Map Navigation Game

An interactive, tap-friendly map navigation game for Grade 2 students.

## What is included

- 5 destination challenges
- A moving student marker
- Compass rose
- Large direction buttons
- Progress tracking
- Final celebration screen
- Fixed junction checkpoints aligned to road intersections

## Deploy on Render

Create a new **Static Site** on Render and connect this GitHub repository.

Use these settings if Render asks for them manually:

- Build Command: `echo "No build step required"`
- Publish Directory: `.`

This repository also includes `render.yaml`, so Render can use it as a Blueprint.
